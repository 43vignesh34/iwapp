What kind of file is `config`?                                                                      |
| 2026-11-08 | Peer dependencies                         | A package declaring "I work with your copy of X, versions A–B". | 2026-11-08 | Turborepo task graph                      | `turbo.json` declares which tasks depend on which (`^build` means "build my dependencies first") and caches results, so unchanged packages are skipped.                                  | [Turborepo docs](https://turborepo.com/docs/crafting-your-repository/configuring-tasks)                                                       | Run `pnpm build` twice. | 2026-11-08 | `tsconfig` `extends` and `strict`         | Every workspace inherits one strict compiler preset from `packages/config/tsconfig/base.json`. `strict` turns on null checks, no implicit `any`, and more.                               | [TSConfig reference](https://www.typescriptlang.org/tsconfig/#strict)                                                                         | In `packages/shared/src/index.ts`, write `const xs = [1]; const n: number = xs[5];`. Which option makes `pnpm typecheck` reject it?                    |
| 2026-11-08 | ESLint flat config and type-aware linting | `eslint.config.js` is a list of config objects. typescript-eslint's `strictTypeChecked` rules ask the compiler about types, so they catch bugs that syntax-only rules can't.             | [typescript-eslint docs](https://typescript-eslint.io/getting-started/typed-linting)                                                          | Add `async function f() {}` and a bare `f();` to a file, then run `pnpm lint`. Read the rule's docs page to see why a "floating" promise is dangerous. |
| 2026-11-08 | Prettier                                  | Formats code automatically so reviews never argue about style. CI fails if a file isn't formatted.                                                                                       | [Prettier docs](https://prettier.io/docs/why-prettier)                                                                                        | Mangle the indentation in `README.md`, run `pnpm format:check`, then `pnpm format`.                                                                    |
| 2026-11-08 | GitHub Actions workflow                   | YAML in `.github/workflows/`: _triggers_ (`on:`), _jobs_ that run on fresh VMs, and _steps_ that are either `run:` shell commands or reusable `uses:` actions.                           | [GitHub docs](https://docs.github.com/en/actions/writing-workflows/workflow-syntax-for-github-actions)                                        | Open the Actions tab on your PR and click into the "Format, lint…" job. Which step took longest?                                                       |
| 2026-11-08 | Least-privilege `permissions:`            | Each workflow gets a token. | 2026-11-08 | Secret scanning (gitleaks)                | Scans every commit for things that look like keys or tokens.
