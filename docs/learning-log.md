| 2026-11-08 | `tsconfig` `extends` and `strict`         | Every workspace inherits one strict compiler preset from `packages/config/tsconfig/base.json`. `strict` turns on null checks, no implicit `any`, and more.                                                                           | [TSConfig reference](https://www.typescriptlang.org/tsconfig/#strict)                                                                         | In `packages/shared/src/index.ts`, write `const xs = [1]; const n: number = xs[5];`. | 2026-11-08 | ESLint flat config and type-aware linting | `eslint.config.js` is a list of config objects. typescript-eslint's `strictTypeChecked` rules ask the compiler about types, so they catch bugs that syntax-only rules can't.                                                         | [typescript-eslint docs](https://typescript-eslint.io/getting-started/typed-linting)                                                          | Add `async function f() {}` and a bare `f();` to a file, then run `pnpm lint`. | 2026-11-08 | Prettier                                  | Formats code automatically so reviews never argue about style. | 2026-11-08 | GitHub Actions workflow                   | YAML in `.github/workflows/`: _triggers_ (`on:`), _jobs_ that run on fresh VMs, and _steps_ that are either `run:` shell commands or reusable `uses:` actions.                                                                       | [GitHub docs](https://docs.github.com/en/actions/writing-workflows/workflow-syntax-for-github-actions)                                        | Open the Actions tab on your PR and click into the "Format, lint…" job. | 2026-11-08 | Least-privilege `permissions:`            | Each workflow gets a token. | 2026-11-08 | Secret scanning (gitleaks)                | Scans every commit for things that look like keys or tokens. | 2026-11-08 | Architecture Decision Records             | A short note per decision (context, decision, consequences), so future maintainers know _why_, not just _what_.                                                                                                                      | [adr.github.io](https://adr.github.io/madr/)                                                                                                  | Write ADR 0005 (it's your `TODO(human)` in T1).                                                                                                        |
| 2026-11-08 | Conventional Commits                      | Commit messages start with `feat:`, `fix:`, `chore:`, `docs:`… This makes history readable and lets tools generate changelogs.                                                                                                       | [conventionalcommits.org](https://www.conventionalcommits.org/en/v1.0.0/)                                                                     | Run `git log --oneline`. | 2026-11-08 | Docker Compose healthchecks and `--wait`  | A healthcheck tells Docker when a container is actually _ready_, not just started. `docker compose up --wait` blocks until every service is healthy, so the API never boots against a Postgres that isn't accepting connections yet. | [Compose docs](https://docs.docker.com/reference/compose-file/services/#healthcheck)                                                          | Run `docker compose ps` straight after `pnpm dev` and watch the status go from `starting` to `healthy`.                                                |
| 2026-11-08 | Validated configuration                   | Parse `process.env` with a Zod schema once at startup. Then try `HOST=` (empty). Should that pass?                                                              |
| 2026-11-08 | Node type stripping                       | Node 24 runs `.ts` files by deleting the types. Which compiler option rejects it?                                                       |
| 2026-11-08 | Fastify plugins and encapsulation         | `app.register(fn)` creates a child context. Hooks and handlers set inside it apply only to its routes. That's why the error handler is set on the root app.                                                                          | [Fastify docs](https://fastify.dev/docs/latest/Reference/Encapsulation/)                                                                      | Move `registerProblemHandlers(app)` inside `app.register(async (child) => …)` and run `pnpm test`. Which tests fail, and why?                          |
| 2026-11-08 | Zod type provider                         | One Zod schema per route gives runtime validation, TypeScript types for `req.body` and the response, and the OpenAPI document. They can't drift apart.                                                                               | [fastify-type-provider-zod](https://github.com/turkerdev/fastify-type-provider-zod)                                                           | In the test echo route, hover over `req.body` in your editor. Where did its type come from?                                                            |
| 2026-11-08 | OpenAPI and Swagger UI                    | A machine-readable description of the API (`/docs/json`) and an interactive page to try it (`/docs`). | 2026-11-08 | RFC 9457 problem details                  | One JSON shape for every error (`type`, `title`, `status`, `detail`), plus our stable `code` and `requestId`. | 2026-11-08 | Liveness vs readiness                     | `/healthz` means "the process is alive" (failing it gets the instance restarted). `/readyz` means "the API can do its job" (failing it stops traffic, without a restart).                                                            | [Kubernetes docs](https://kubernetes.io/docs/concepts/configuration/liveness-readiness-startup-probes/)                                       | Why would checking Postgres in `/healthz` be harmful during a short database outage?                                                                   |
| 2026-11-08 | Request IDs                               | One ID per request, in the response header, the error body and (from T3) every log line, so a user's report can be matched to the exact logs. Now try an ID containing a space.                                                   |
| 2026-11-08 | Helmet security headers                   | Sets headers that tell browsers to be strict: CSP (what may load), `nosniff`, HSTS, frame-ancestors.                                                                                                                                 | [Helmet](https://helmetjs.github.io/)                                                                                                         | Run `curl -I localhost:4000/healthz` and look up one header you don't recognise on MDN.                                                                |
